# Scientific provenance and integrity

Experiments are organized directly as W1, W2, W3, S1, S2 and S3. Current result packages contain numerical CSVs, selected field arrays, vector figures and file manifests. They are not presentation wrappers for results under another numbering scheme and cannot restore training.

Full training directories, original predictions, models and original reports are stored outside the repository. `experiments.provenance.external_source(key)` resolves their actual locations through an external registry; the default is the adjacent `experiment_sources.json`, overridable with `GIFT_EXPERIMENT_SOURCE_REGISTRY` or `GIFT_SOURCE_<KEY>`. Documentation names `prediction_native`, `prediction_extension` and `prediction_aligned` are source keys that must first resolve to actual directories.

| Source key | Contents |
| --- | --- |
| `prediction_native` | Loadable GIFT, FNO-2D and FNO-3D training states and shared observations |
| `prediction_extension` | Loadable U-NO, U-Net and GIFT-Lite states and cross-grid configurations |
| `prediction_aligned` | Loadable ANIE state and W1 training configuration |

```python
from experiments.provenance import external_source
prediction_root = external_source("prediction_extension")
```

Normalized identity metadata for loadable states is retained separately from measurement-time versions. Their model tensors, optimizer, RNG, normalizer and observation arrays are bitwise identical; these states were not retrained. Original reports, training histories, raw arrays and actual measurement weights are preserved.

Loadable S3 data uses the current identity `gaussian_s3`, with local data root `../GIFT-dataset`; `s3_gaussian/trajectories.h5` and `lite.h5` contain bitwise copies of original observation arrays. Current published models use the same S3 identity and frozen-generator bindings. Arrays, model tensors, optimizer, RNG and training budgets retain their original values; SHA changes from identity metadata do not indicate regenerated data, retraining or new measurements. Actual loadable-file SHAs are registered in `artifacts/CHECKPOINTS.json`; measurement-time weight SHAs for published values and original reports are preserved. Local equivalence evidence is stored outside the repository in `S3_CANONICAL_DATA_MIRROR.json` and `S3_PACKAGED_METADATA_NORMALIZATION.json`.

The source registry only locates evidence; it does not transform observations or select weights. References to `source_record_id` or `source-record:` in result manifests identify complete original metadata outside the repository; the local registry is `../repository_audits/rename_w3_20261007/SOURCE_PROVENANCE.json`. Each current reference binds the original file SHA and its JSON location. SHAs of original reports, training histories, raw arrays and measurement weights remain unchanged; sizes and SHAs of current public files bind their actual bytes.

Experiment identities and paths are metadata and do not establish retraining or recomputation. W1/W2 and S1–S3 numerical values and existing figures retain the original measurements. Current formal noise-free W3 results come from run `w3_single_trajectory_20261010`: 50 fixed parameter combinations, one local ID0 trajectory per case, with all 250 slots and 750 rows completed. All locally locked scientific-source SHAs match SOURCE_LOCK; 24 remote files are bound by a passing deployment receipt, and numerical-package manifests pass file-by-file checks. External algorithm runtimes and official checkouts remain outside the GIFT project directory. The W3 package contains numerical values, coefficient supports, protocols, provenance manifests and [three parameter-specific absolute percentage error distributions in Figure 4a–c](../results/formal/W3_single_trajectory_20261010/figures/parameter_distributions/w3_parameter_nu_errors.svg), without external implementation code. The figures compute each APE as 100×|estimate−truth|/|truth| from the same 750 parameter readouts, using one full-range panel per parameter; seven equally spaced horizontal lanes organize dots without changing their APE coordinates. Dots have a nominal diameter of 2.1 pt, and adjacent lanes are separated by 2.7 pt for a compact point layer. Each real point comprises 12 concentric, stroke-free transparent discs of the same color, with a radial Gaussian alpha profile for soft edges (sigma 0.42 relative to the radius; nominal central alpha 0.95). This softens individual real markers without KDE, data smoothing or artificial observations. Solid Tukey boxes show Q1–Q3 of individual APEs; the extended line through each box and the row's Median value show the median of 50 APEs. Thin whiskers with short caps end at the outermost actual observations within the inclusive fences [Q1−1.5×IQR, Q3+1.5×IQR], with IQR=Q3−Q1. All actual points, including those beyond the whiskers, are retained without duplicate flier symbols or separate mean markers. Plot text is limited to bold black method names, ticks, parameter-specific horizontal-axis labels and each method's numerical Median value. Axes are solid; dots, solid boxes and whiskers share saturated dark method colors. Median lines exactly match their box color, with width 1.6 pt and length about 2.1 times the box height. Horizontal ticks point upward into the plot and labels remain below the axis; the axis extends beyond the final tick by 3% of its current span without changing data coordinates or tick positions. Point coordinates, rendering entry points and file SHAs are separately bound in the [figure manifest](../results/formal/W3_single_trajectory_20261010/figures/parameter_distributions/figure_manifest.json). Closed training protocols, scientific-source locks and cost manifests retain their original bytes. Method objectives, observation processing and budgets differ, so these are not architecture comparisons with equal information or budgets. Provenance, measured costs and the full audit are in the [W3 result manifest](../results/formal/W3_single_trajectory_20261010/published.json).
